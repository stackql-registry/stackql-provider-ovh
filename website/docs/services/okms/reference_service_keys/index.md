## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Returns the valid combinations of key type, size, curve, operations and protection level for a region. Use it before creating or importing a service key.

```sql
SELECT
curves,
default,
operations,
protection_level,
sizes,
type
FROM ovh.okms.reference_service_keys
WHERE region = '{{ region }}' -- required
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
;
```
</TabItem>
