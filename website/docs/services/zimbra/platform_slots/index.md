## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the offer and billing status of the slot, and the email account using it. `accountId` and `email` are null while no account uses the slot.

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
resource_status
FROM ovh.zimbra.platform_slots
WHERE platform_id = '{{ platform_id }}' -- required
AND slot_id = '{{ slot_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the account slots of the platform with their offer, billing status and linked email account. Filter them by `accountId`, `email`, `offer`, `billingStatus` or `used`.

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
resource_status
FROM ovh.zimbra.platform_slots
WHERE platform_id = '{{ platform_id }}' -- required
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND account_id = '{{ account_id }}'
AND billing_status = '{{ billing_status }}'
AND email = '{{ email }}'
AND offer = '{{ offer }}'
AND used = '{{ used }}'
;
```
</TabItem>
</Tabs>
