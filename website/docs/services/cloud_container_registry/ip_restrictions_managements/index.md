List your IP restrictions applied on Harbor UI and API

```sql
SELECT
created_at,
description,
ip_block,
updated_at
FROM ovh.cloud_container_registry.ip_restrictions_managements
WHERE registry_id = '{{ registry_id }}' -- required
AND service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
