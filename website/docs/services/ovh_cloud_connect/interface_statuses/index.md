Returns whether the port is up or down, with its last up, down and change times. (Beta version)

```sql
SELECT
last_change,
last_down,
last_up,
last_update,
status
FROM ovh.ovh_cloud_connect.interface_statuses
WHERE id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
