## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the circuit's pairing key, status and operational status.

```sql
SELECT
id,
name,
creation_date,
done_date,
key,
last_update,
operational_status,
status
FROM ovh.ovh_cloud_connect.circuits
WHERE id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the IDs of the circuits created from Google pairing keys.

```sql
SELECT
id,
name,
creation_date,
done_date,
key,
last_update,
operational_status,
status
FROM ovh.ovh_cloud_connect.circuits
WHERE service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>
