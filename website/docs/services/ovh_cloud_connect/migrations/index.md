<Tabs
    defaultValue="get"
    values={[

<TabItem value="get">

Returns the migration type (repricing or total), product, status and dates.

```sql
SELECT
id,
service_id,
product_name,
creation_date,
done_date,
status,
type
FROM ovh.ovh_cloud_connect.migrations
WHERE service_name = '{{ service_name }}' -- required
;
```
