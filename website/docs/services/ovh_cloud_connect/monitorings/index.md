## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Returns each alert type available on the service and whether it is active.

```sql
SELECT
name,
activated,
description,
type
FROM ovh.ovh_cloud_connect.monitorings
WHERE service_name = '{{ service_name }}' -- required
;
```
</TabItem>
</Tabs>
