## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[

<TabItem value="get">

Returns the name, distribution and version of an image that can be installed on the VPS. (Beta version)

```sql
SELECT
id,
name
FROM ovh.vps.images_availables
WHERE id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the names of the images that can be installed on the VPS. (Beta version)

```sql
SELECT
id,
name
FROM ovh.vps.images_availables
WHERE service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
