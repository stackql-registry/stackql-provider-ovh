## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Returns the ID, creation date, description and region of the snapshot of the VPS.

```sql
SELECT
id,
creation_date,
description,
region
FROM ovh.vps.snapshots
WHERE service_name = '{{ service_name }}' -- required
;
```
</TabItem>
</Tabs>


## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Updates the description of the snapshot of the VPS.

```sql
UPDATE ovh.vps.snapshots
SET 
description = '{{ description }}'
WHERE 
service_name = '{{ service_name }}' --required;
```
</TabItem>
</Tabs>

<Tabs

