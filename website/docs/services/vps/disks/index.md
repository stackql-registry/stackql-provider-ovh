## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the type, size, state, monitoring, bandwidth limit and low free space threshold of a disk of the VPS.

```sql
SELECT
id,
service_name,
bandwidth_limit,
low_free_space_threshold,
monitoring,
size,
state,
type
FROM ovh.vps.disks
WHERE id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the IDs of the disks attached to the VPS.

```sql
SELECT
id,
service_name,
bandwidth_limit,
low_free_space_threshold,
monitoring,
size,
state,
type
FROM ovh.vps.disks
WHERE service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

Updates the monitoring state and the low free space threshold of a disk of the VPS.

```sql
UPDATE ovh.vps.disks
SET 
low_free_space_threshold = {{ low_free_space_threshold }},
monitoring = {{ monitoring }}
WHERE 
id = '{{ id }}' --required
AND service_name = '{{ service_name }}' --required;
```
