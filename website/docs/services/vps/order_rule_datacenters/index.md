Returns the datacenters available for a VPS order, with their priority and stock status.

```sql
SELECT
datacenters
FROM ovh.vps.order_rule_datacenters
WHERE ovh_subsidiary = '{{ ovh_subsidiary }}' -- required
AND plan_code = '{{ plan_code }}' -- required
AND os = '{{ os }}'
;
```
