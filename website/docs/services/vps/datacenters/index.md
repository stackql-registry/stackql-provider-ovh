## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the name, long name and country of the datacenter of the VPS.

```sql
SELECT
name,
long_name,
country
FROM ovh.vps.datacenters
WHERE service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List all VPS datacenters available for the given country

```sql
SELECT
value
FROM ovh.vps.datacenters
WHERE country = '{{ country }}'
;
```
</TabItem>
</Tabs>
