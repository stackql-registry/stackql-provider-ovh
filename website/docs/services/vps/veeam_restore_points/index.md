<TabItem value="get">

Returns the ID and the creation time of a Veeam restore point of the VPS. (Deprecated, will be removed)

```sql
SELECT
id,
creation_time
FROM ovh.vps.veeam_restore_points
WHERE id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the IDs of the Veeam restore points available for the VPS. (Deprecated, will be removed)

```sql

id,
creation_time
FROM ovh.vps.veeam_restore_points
WHERE service_name = '{{ service_name }}' -- required
AND creation_time = '{{ creation_time }}'
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
