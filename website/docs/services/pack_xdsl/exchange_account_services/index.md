## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },

>
<TabItem value="get">

Get an Exchange 2013 account service of an xDSL pack. Returns the domain, organization and Exchange service of an account activated with the pack.

```sql
SELECT
organization_name,
domain,
exchange_service
FROM ovh.pack_xdsl.exchange_account_services
WHERE domain = '{{ domain }}' -- required
AND pack_name = '{{ pack_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List the Exchange 2013 account services of an xDSL pack. Returns the domains of the Exchange 2013 accounts activated with the pack.

```sql
SELECT
organization_name,
domain,
exchange_service
FROM ovh.pack_xdsl.exchange_account_services
WHERE pack_name = '{{ pack_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
