Get the promotion code capabilities of an xDSL pack. Returns whether a promotion code can be generated, its amount, the engagement it requires and the reasons when it cannot.

```sql
SELECT
amount,
can_generate,
engagement,
reason_codes
FROM ovh.pack_xdsl.promotion_code_capabilities
WHERE pack_name = '{{ pack_name }}' -- required
;
```
