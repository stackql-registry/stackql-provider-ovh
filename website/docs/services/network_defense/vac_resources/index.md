## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns a VAC DDoS protection resource with its name, status and creation and update dates. The status is READY, or DELETING while the resource is being removed.

```sql
SELECT
id,
name,
created_at,
iam,
resource_status,
updated_at
FROM ovh.network_defense.vac_resources
WHERE resource_name = '{{ resource_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the list of VAC DDoS protection resources within the account. Every resource groups policies, profile and sensitivity with target IP address prefixes in order to tune detection and mitigation rules.

```sql
SELECT
id,
name,
created_at,
iam,
resource_status,
updated_at
FROM ovh.network_defense.vac_resources
WHERE x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND iam_tags = '{{ iam_tags }}'
;
```
</TabItem>
</Tabs>

<TabItem value="update">

Changes the name of a VAC DDoS protection resource. No other field can be updated through this call.

```sql
UPDATE ovh.network_defense.vac_resources
SET 
name = '{{ name }}'
WHERE 
resource_name = '{{ resource_name }}' --required
AND name = '{{ name }}' --required
RETURNING
id,
name,
created_at,
resource_status,
updated_at;
```
