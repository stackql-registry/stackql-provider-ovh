<TabItem value="list">

List the regions on which you can ask an access to

```sql
SELECT
name,
continent_code,
datacenter_location,
type
FROM ovh.cloud.region_availables
WHERE service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
