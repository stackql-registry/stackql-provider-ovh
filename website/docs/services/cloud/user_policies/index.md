Export user storage policy (Beta version)

```sql
SELECT
policy
FROM ovh.cloud.user_policies
WHERE user_id = '{{ user_id }}' -- required
AND service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
