## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Get storage quotas on region

```sql
SELECT
bytes_used,
container_count,
object_count,
quota_bytes
FROM ovh.cloud.region_quota_storages
WHERE region_name = '{{ region_name }}' -- required
AND service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
</Tabs>

<Tabs
    defaultValue="update"

<TabItem value="update">

Update storage quota on region

```sql
UPDATE ovh.cloud.region_quota_storages
SET 
quota_bytes = {{ quota_bytes }}
WHERE 
region_name = '{{ region_name }}' --required
AND service_name = '{{ service_name }}' --required unless OVH_CLOUD_PROJECT_SERVICE is set
AND quota_bytes = '{{ quota_bytes }}' --required;
```
</TabItem>
</Tabs>
