List required agreements to active this lab (Beta version)

```sql
SELECT
accepted,
to_accept
FROM ovh.cloud.lab_agreements
WHERE lab_id = '{{ lab_id }}' -- required
AND service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
