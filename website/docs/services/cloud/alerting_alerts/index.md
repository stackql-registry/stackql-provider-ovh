## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns when the alert was sent and to which email addresses.

```sql
SELECT
alert_id,
alert_date,
emails
FROM ovh.cloud.alerting_alerts
WHERE alert_id = '{{ alert_id }}' -- required
AND id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">

Returns the IDs of the alerts already sent for this billing alert.

```sql
SELECT
alert_id,
alert_date,
emails
FROM ovh.cloud.alerting_alerts
WHERE id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>
