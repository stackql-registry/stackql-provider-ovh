Get list of transactions between two dates

```sql
SELECT
id,
service_id,
begin_date,
creation_date,
elements,
end_date,
last_update,
price
FROM ovh.me.consumption_usage_histories
WHERE begin_date = '{{ begin_date }}' -- required
AND end_date = '{{ end_date }}' -- required
;
```
