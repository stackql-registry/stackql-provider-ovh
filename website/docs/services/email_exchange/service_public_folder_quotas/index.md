Get the public folder quota. Returns the total space of the public folders, the space already reserved and the space used, in MB.

```sql
SELECT
quota_limit,
quota_reserved,
quota_used
FROM ovh.email_exchange.service_public_folder_quotas
WHERE exchange_service = '{{ exchange_service }}' -- required
AND organization_name = '{{ organization_name }}' -- required
;
```
