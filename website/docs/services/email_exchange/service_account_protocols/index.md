## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Get the account protocols. Returns whether POP, IMAP, webmail and ActiveSync are enabled on the email account.

```sql
SELECT
task_pending_id,
active_sync,
creation_date,
imap,
last_update,
pop,
web_mail
FROM ovh.email_exchange.service_account_protocols
WHERE exchange_service = '{{ exchange_service }}' -- required
AND organization_name = '{{ organization_name }}' -- required
AND primary_email_address = '{{ primary_email_address }}' -- required
;
```
</TabItem>
</Tabs>

Update the account protocols. Enables or disables POP, IMAP, webmail and ActiveSync on the email account.

```sql
UPDATE ovh.email_exchange.service_account_protocols
SET 
imap = {{ imap }},
pop = {{ pop }},
active_sync = {{ active_sync }},
web_mail = {{ web_mail }}
WHERE 
exchange_service = '{{ exchange_service }}' --required
AND organization_name = '{{ organization_name }}' --required
AND primary_email_address = '{{ primary_email_address }}' --required;
```
</TabItem>
