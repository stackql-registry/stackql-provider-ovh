## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Get the PST export. Returns the creation date and the completion percentage of the PST export of the email account.

```sql
SELECT
task_pending_id,
creation_date,
percent_complete
FROM ovh.email_exchange.service_account_exports
WHERE exchange_service = '{{ exchange_service }}' -- required
AND organization_name = '{{ organization_name }}' -- required
AND primary_email_address = '{{ primary_email_address }}' -- required
;
```
</TabItem>
</Tabs>
