## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the subnet, including its gateway IP and allocation pools.

```sql
SELECT
id,
checksum,
created_at,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at
FROM ovh.public_cloud_network.network_subnets
WHERE network_id = '{{ network_id }}' -- required
AND subnet_id = '{{ subnet_id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">

Returns the subnets of the network.

```sql

```

'{{ project_id }}'

<Tabs

Updates the subnet's name, description, DHCP, DNS nameservers, gateway or allocation pools. The CIDR is immutable.

```sql
UPDATE ovh.public_cloud_network.network_subnets
SET 
checksum = '{{ checksum }}',
target_spec = '{{ target_spec }}'
WHERE 
network_id = '{{ network_id }}' --required
AND subnet_id = '{{ subnet_id }}' --required
AND project_id = '{{ project_id }}' --required unless OVH_CLOUD_PROJECT_SERVICE is set
AND target_spec = '{{ target_spec }}' --required
RETURNING
id,
checksum,
created_at,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at;
```
