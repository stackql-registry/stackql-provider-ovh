## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[

<TabItem value="get">

Returns the additional IP, including the resource it's associated with.

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
resource_status
FROM ovh.public_cloud_network.public_ip_additionals
WHERE id = '{{ id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">

Returns the additional IPs of the project.

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
resource_status
FROM ovh.public_cloud_network.public_ip_additionals
WHERE project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
;
```
