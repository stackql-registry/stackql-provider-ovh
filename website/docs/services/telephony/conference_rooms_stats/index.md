Get live room statistics

```sql
SELECT
active_rooms_count,
participants_count,
rooms_count
FROM ovh.telephony.conference_rooms_stats
WHERE billing_account = '{{ billing_account }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
