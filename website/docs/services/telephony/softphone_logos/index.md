## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Returns the softphone logo of the billing account: file name and download URL.

```sql
SELECT
filename,
url
FROM ovh.telephony.softphone_logos
WHERE billing_account = '{{ billing_account }}' -- required
;
```
</TabItem>
</Tabs>


## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Sets the softphone logo of the billing account from a file name and a URL.

```sql
UPDATE ovh.telephony.softphone_logos
SET 
filename = '{{ filename }}',
url = '{{ url }}'
WHERE 
billing_account = '{{ billing_account }}' --required
AND filename = '{{ filename }}' --required
AND url = '{{ url }}' --required
RETURNING
filename,
url;
```
</TabItem>
</Tabs>
