## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Returns the softphone theme of the line and its main color code.

```sql
SELECT
theme_id,
color
FROM ovh.telephony.line_softphone_themes
WHERE billing_account = '{{ billing_account }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
</Tabs>


## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Sets the softphone theme of the line from a theme identifier.

```sql
UPDATE ovh.telephony.line_softphone_themes
SET 
theme_id = {{ theme_id }}
WHERE 
billing_account = '{{ billing_account }}' --required
AND service_name = '{{ service_name }}' --required
AND theme_id = '{{ theme_id }}' --required
RETURNING
theme_id,
color;
```
</TabItem>
</Tabs>
