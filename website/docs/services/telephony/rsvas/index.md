## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a premium rate number

```sql
SELECT
service_name,
typology
FROM ovh.telephony.rsvas
WHERE billing_account = '{{ billing_account }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List premium rate numbers

```sql
SELECT
service_name,
typology
FROM ovh.telephony.rsvas
WHERE billing_account = '{{ billing_account }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

Update a premium rate number

```sql
UPDATE ovh.telephony.rsvas
SET 
typology = '{{ typology }}'
WHERE 
billing_account = '{{ billing_account }}' --required
AND service_name = '{{ service_name }}' --required;
```

## Lifecycle Methods

EXEC variables use wire (API) names.

    defaultValue="cancel_scheduled_rate_code"

<TabItem value="cancel_scheduled_rate_code">

Cancel the scheduled rate code

```sql
EXEC ovh.telephony.rsvas.cancel_scheduled_rate_code 
@billingAccount='{{ billingAccount }}' --required, 
@serviceName='{{ serviceName }}' --required
;
```
</TabItem>
<TabItem value="schedule_rate_code">

Schedule a rate code

```sql
EXEC ovh.telephony.rsvas.schedule_rate_code 
@billingAccount='{{ billingAccount }}' --required, 
@serviceName='{{ serviceName }}' --required 
@@json=
'{
"rateCode": "{{ rateCode }}"
}'
;
```
</TabItem>
