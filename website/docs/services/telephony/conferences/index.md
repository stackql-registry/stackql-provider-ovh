## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a conference service

```sql
SELECT
service_name,
description,
offers,
service_type
FROM ovh.telephony.conferences
WHERE billing_account = '{{ billing_account }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List conference services

```sql
SELECT
service_name,
description,
offers,
service_type
FROM ovh.telephony.conferences
WHERE billing_account = '{{ billing_account }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

Upload the welcome announcement

```sql
EXEC ovh.telephony.conferences.announce_upload 
@billingAccount='{{ billingAccount }}' --required, 
@serviceName='{{ serviceName }}' --required 
@@json=
'{
"documentId": "{{ documentId }}"
}'
;
```
</TabItem>
