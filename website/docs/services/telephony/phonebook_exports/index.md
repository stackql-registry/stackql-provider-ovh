Export contacts

```sql
SELECT
filename,
status,
url,
url_expiration_datetime
FROM ovh.telephony.phonebook_exports
WHERE billing_account = '{{ billing_account }}' -- required
AND book_key = '{{ book_key }}' -- required
AND format = '{{ format }}' -- required
;
```
