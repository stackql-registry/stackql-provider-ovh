## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },

    ]}
>
<TabItem value="get">

Get a Carrier SIP service

```sql
SELECT
service_name,
description,
service_type
FROM ovh.telephony.carrier_sips
WHERE billing_account = '{{ billing_account }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List Carrier SIP services

```sql
SELECT
service_name,
description,
service_type
FROM ovh.telephony.carrier_sips
WHERE billing_account = '{{ billing_account }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
