## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },

>
<TabItem value="get">

Get a sound

```sql
SELECT
name,
sound_id
FROM ovh.telephony.easy_hunting_sounds
WHERE billing_account = '{{ billing_account }}' -- required
AND service_name = '{{ service_name }}' -- required
AND sound_id = '{{ sound_id }}' -- required
;
```
</TabItem>
