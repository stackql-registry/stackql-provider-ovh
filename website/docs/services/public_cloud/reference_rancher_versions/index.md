## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Returns the versions available for creating a managed Rancher service, with their status, changelog URL and the cause when a version is unavailable.

```sql
SELECT
name,
cause,
changelog_url,
message,
status
FROM ovh.public_cloud.reference_rancher_versions
WHERE project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
;
```
