Returns the minor versions available for cluster creation, newest first, and the default version. Creation resolves a minor version to its latest patch. (Beta version)

```sql
SELECT
available_versions,
default_version
FROM ovh.public_cloud.reference_managed_kubernetes_versions
WHERE project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
