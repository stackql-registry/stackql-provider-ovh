## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the SSH key with its public key content.

```sql
SELECT
name,
created_at,
public_key,
updated_at
FROM ovh.public_cloud.ssh_keys
WHERE name = '{{ name }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">

Returns the SSH public keys stored in the project.

```sql
SELECT
name,
created_at,
public_key,
updated_at
FROM ovh.public_cloud.ssh_keys
WHERE project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
;
```
</TabItem>
</Tabs>

<Tabs

<TabItem value="create">

Stores an SSH public key under a name that is unique in the project. Use this name to install the key on an instance at creation.

```sql
INSERT INTO ovh.public_cloud.ssh_keys (
name,
public_key,
project_id
)
SELECT 
'{{ name }}' /* required */,
'{{ public_key }}' /* required */,
'{{ project_id }}'
RETURNING
name,
created_at,
public_key,
updated_at
;
```
</TabItem>

## `DELETE` examples

<Tabs
    defaultValue="delete"
    values={[

<TabItem value="delete">

Deletes the SSH key from the project. Instances created with this key keep it.

```sql
DELETE FROM ovh.public_cloud.ssh_keys
WHERE name = '{{ name }}' --required
AND project_id = '{{ project_id }}' --required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
