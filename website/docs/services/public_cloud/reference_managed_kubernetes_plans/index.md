## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }

>
<TabItem value="list">

Returns the plans available for cluster creation in a region, with their control plane characteristics and limits. Requires a region. (Beta version)

```sql
SELECT
name,
control_plane,
limits,
status
FROM ovh.public_cloud.reference_managed_kubernetes_plans
WHERE region = '{{ region }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
;
```
