## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the project, its current state and its ongoing tasks.

```sql
SELECT
id,
name,
created_at,
current_state,
current_tasks,
iam,
resource_status,
target_spec,
updated_at
FROM ovh.public_cloud.projects
WHERE project_id = '{{ project_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the projects of the account with their current state.

```sql
SELECT
id,
name,
created_at,
current_state,
current_tasks,
iam,
resource_status,
target_spec,
updated_at
FROM ovh.public_cloud.projects
WHERE x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND iam_tags = '{{ iam_tags }}'
;
```
</TabItem>
