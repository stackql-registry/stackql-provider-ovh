Returns the dated log messages of the deployment.

```sql
SELECT
date,
message
FROM ovh.hosting_web.website_deployment_logs
WHERE deployment_id = '{{ deployment_id }}' -- required
AND id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
