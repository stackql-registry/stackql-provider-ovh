Generate URL to logs archive

```sql
SELECT
url,
validity
FROM ovh.hosting_web.cdn_domain_logs
WHERE domain_name = '{{ domain_name }}' -- required
AND service_name = '{{ service_name }}' -- required
AND date = '{{ date }}'
;
```
