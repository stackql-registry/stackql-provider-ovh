## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get an email option. Returns the domain and creation date of the email option. Its billing information is returned by serviceInfos.

```sql
SELECT
id,
creation_date,
domain
FROM ovh.hosting_web.email_options
WHERE id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List email options. Returns the IDs of the email options of the hosting. Each option is a mail service linked to the hosting.

```sql
SELECT
id,
creation_date,
domain
FROM ovh.hosting_web.email_options
WHERE service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>
