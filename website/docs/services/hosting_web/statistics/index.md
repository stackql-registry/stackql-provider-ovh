<TabItem value="list">

Get statistics. Returns one statistic of the hosting over a period: HTTP hits, mean response time, FTP commands, outgoing TCP connections, CPU usage or worker overload.

```sql
SELECT
serie_name,
unit,
values
FROM ovh.hosting_web.statistics
WHERE period = '{{ period }}' -- required
AND service_name = '{{ service_name }}' -- required
AND type = '{{ type }}' -- required
;
```
