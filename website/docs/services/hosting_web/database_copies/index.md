## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a database copy. Returns the status, creation date and expiration date of the copy. Restore it into the database with copyRestore.

```sql
SELECT
id,
creation_date,
expiration_date,
last_update,
status
FROM ovh.hosting_web.database_copies
WHERE id = '{{ id }}' -- required
AND name = '{{ name }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List database copies. Returns the IDs of the copies of the database. Each copy is kept until its expiration date.

```sql
SELECT
id,
creation_date,
expiration_date,
last_update,
status
FROM ovh.hosting_web.database_copies
WHERE name = '{{ name }}' -- required
AND service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

Create a database copy. Creates a copy of the database, kept until its expiration date. Restore it later with copyRestore.

```sql

name,
service_name

'{{ service_name }}'
RETURNING
id,
creation_date,
expiration_date,
last_update,
status
;
```
