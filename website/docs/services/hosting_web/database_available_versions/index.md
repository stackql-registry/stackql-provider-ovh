List database versions. Returns the available versions of a database type, and the version used when a database is created without one.

```sql
SELECT
default,
list
FROM ovh.hosting_web.database_available_versions
WHERE service_name = '{{ service_name }}' -- required
AND type = '{{ type }}' -- required
;
```
