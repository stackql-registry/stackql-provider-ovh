## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get the details of the dedicated server resource. (Beta version)

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
iam,
resource_status,
target_spec
FROM ovh.dedicated_server_v2.servers
WHERE service_name = '{{ service_name }}' -- required
AND actions = '{{ actions }}'
;
```
</TabItem>
<TabItem value="list">

Get the list of all my dedicated server resources. (Beta version)

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
iam,
resource_status,
target_spec
FROM ovh.dedicated_server_v2.servers
WHERE iam_tags = '{{ iam_tags }}'
;
```
</TabItem>
</Tabs>
