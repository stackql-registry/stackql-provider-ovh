Get the installation status. Returns the progress of the operating system installation on the server: the elapsed time in seconds and the status of each step. When no installation is in progress, the call returns an error.

```sql
SELECT
elapsed_time,
progress
FROM ovh.dedicated_server.install_statuses
WHERE service_name = '{{ service_name }}' -- required
;
```
