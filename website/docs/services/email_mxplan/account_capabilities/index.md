Get email account capabilities. Returns the quotas that can be set on the email account. No value means that any quota is allowed.

```sql
SELECT
quotas
FROM ovh.email_mxplan.account_capabilities
WHERE email = '{{ email }}' -- required
AND service = '{{ service }}' -- required
;
```
