Returns the actions available on the data-gathering tool.

```sql
SELECT
is_allowed,
type
FROM ovh.dbaas_logs.input_actions
WHERE input_id = '{{ input_id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
