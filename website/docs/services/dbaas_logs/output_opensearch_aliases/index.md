<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the alias.

```sql
SELECT
name,
alias_id,
created_at,
description,
iam,
is_editable,
nb_index,
nb_stream,
updated_at
FROM ovh.dbaas_logs.output_opensearch_aliases
WHERE alias_id = '{{ alias_id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
