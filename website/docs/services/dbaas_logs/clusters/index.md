## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the cluster.

```sql
SELECT
cluster_id,
default_retention_id,
archive_allowed_networks,
certification_level,
cluster_type,
dedicated_input_pem,
direct_input_allowed_networks,
direct_input_pem,
hostname,
is_default,
is_unlocked,
query_allowed_networks,
region
FROM ovh.dbaas_logs.clusters
WHERE cluster_id = '{{ cluster_id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the clusters of the Logs Data Platform service.

```sql
SELECT
cluster_id,
default_retention_id,
archive_allowed_networks,
certification_level,
cluster_type,
dedicated_input_pem,
direct_input_allowed_networks,
direct_input_pem,
hostname,
is_default,
is_unlocked,
query_allowed_networks,
region
FROM ovh.dbaas_logs.clusters
WHERE service_name = '{{ service_name }}' -- required
AND name_pattern = '{{ name_pattern }}'
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

archive_allowed_networks = '{{ archive_allowed_networks }}',
direct_input_allowed_networks = '{{ direct_input_allowed_networks }}',
query_allowed_networks = '{{ query_allowed_networks }}'
