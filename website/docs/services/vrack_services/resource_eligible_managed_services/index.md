Returns, by type, the managed services that can get a Service Endpoint in the vRack Services. Only services in the same region are eligible.

```sql
SELECT
managed_service_type,
managed_service_urns
FROM ovh.vrack_services.resource_eligible_managed_services
WHERE vrack_services_id = '{{ vrack_services_id }}' -- required
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
;
```
