Returns, per region, the availability of each feature: bgp, netboot and each compatible managed service type, overall and in each availability zone. A feature missing from a region is not offered there.

```sql
SELECT
features,
region
FROM ovh.vrack_services.reference_feature_availabilities
WHERE x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND region = '{{ region }}'
;
```
