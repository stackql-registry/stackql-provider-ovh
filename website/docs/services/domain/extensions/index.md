## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get an extension

```sql
SELECT
name
FROM ovh.domain.extensions
WHERE name = '{{ name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List all extensions

```sql
SELECT
name
FROM ovh.domain.extensions
WHERE geolocalizations = '{{ geolocalizations }}'
AND order_by = '{{ order_by }}'
AND ovh_subsidiary = '{{ ovh_subsidiary }}'
AND thematics = '{{ thematics }}'
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>
