Retrieve optin configuration

```sql

fields,
type
FROM ovh.domain.configurations_optins
WHERE service_name = '{{ service_name }}' -- required
;
```

```sql

WHERE 
service_name = '{{ service_name }}' --required
RETURNING
fields,
type;
```
