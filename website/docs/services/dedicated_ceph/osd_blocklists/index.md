```sql
SELECT
entries
FROM ovh.dedicated_ceph.osd_blocklists
WHERE service_name = '{{ service_name }}' -- required
;
```

Removes the client session from the OSD blocklist. This may corrupt data: read the Ceph documentation before calling. (Beta version)

```sql
DELETE FROM ovh.dedicated_ceph.osd_blocklists
WHERE address = '{{ address }}' --required
AND service_name = '{{ service_name }}' --required
;
```
