## `SELECT` examples

<Tabs
    defaultValue="get"

<TabItem value="get">

Returns a log kind and the additional fields its logs carry. (Beta version)

```sql
SELECT
name,
kind_id,
display_name,
additional_returned_fields,
created_at,
updated_at
FROM ovh.public_cloud_database.mongodb_log_kinds
WHERE name = '{{ name }}' -- required
AND service_id = '{{ service_id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">

Returns the names of the log kinds MongoDB emits, which can be forwarded to a stream. (Beta version)

```sql
SELECT
name,
kind_id,
display_name,
additional_returned_fields,
created_at,
updated_at
FROM ovh.public_cloud_database.mongodb_log_kinds
WHERE service_id = '{{ service_id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
