<TabItem value="get">

Returns a role that can be assigned to users. (Beta version)

```sql
SELECT
id,
name,
checksum,
created_at,
updated_at
FROM ovh.public_cloud_database.postgresql_roles
WHERE role_id = '{{ role_id }}' -- required
AND service_id = '{{ service_id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
