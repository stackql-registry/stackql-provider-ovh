## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Returns the scraping targets and the username for Prometheus authentication. The password is returned only by a credentials reset. (Beta version)

```sql
SELECT
targets,
username
FROM ovh.public_cloud_database.postgresql_prometheuses
WHERE service_id = '{{ service_id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
</Tabs>
