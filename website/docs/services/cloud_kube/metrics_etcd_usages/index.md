List available metrics for this cluster

```sql
SELECT
quota,
usage
FROM ovh.cloud_kube.metrics_etcd_usages
WHERE kube_id = '{{ kube_id }}' -- required
AND service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
