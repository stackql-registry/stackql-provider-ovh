## `SELECT` examples

<TabItem value="get">

Get specific information of a region (Beta version)

```sql
SELECT
region
FROM ovh.cloud_network.capabilities_loadbalancer_regions
WHERE region_name = '{{ region_name }}' -- required
AND service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">

List all available regions (Beta version)

```sql
SELECT
region
FROM ovh.cloud_network.capabilities_loadbalancer_regions
WHERE service_name = '{{ service_name }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
