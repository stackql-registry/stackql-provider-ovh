    defaultValue="list"

<TabItem value="list">

Returns the domains attached to all the web hostings of the account. Filter them by name with the domain parameter. (Beta version)

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
ip_location,
resource_status
FROM ovh.webhosting.attached_domains
WHERE x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND domain = '{{ domain }}'
;
```
