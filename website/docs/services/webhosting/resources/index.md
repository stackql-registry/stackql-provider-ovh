## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the web hosting, identified by its service name, with its current state and running tasks. (Beta version)

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
iam,
resource_status
FROM ovh.webhosting.resources
WHERE name = '{{ name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the web hostings of the account. (Beta version)

```sql
SELECT
id,
checksum,
current_state,
current_tasks,
iam,
resource_status
FROM ovh.webhosting.resources
WHERE x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND iam_tags = '{{ iam_tags }}'
;
```
</TabItem>
</Tabs>
