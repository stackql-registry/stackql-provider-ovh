Check edge capacity on global datastores. Returns true when the global datastores have enough free space for the edge nodes. Set their number and size with `count` and `size`, MEDIUM by default.

```sql
SELECT
value
FROM ovh.dedicated_cloud.can_deploy_nsxt_edges_on_global_datastores
WHERE service_name = '{{ service_name }}' -- required
AND count = '{{ count }}'
AND size = '{{ size }}'
;
```
