List orderable host profiles. Returns the host profiles that can be ordered in the datacenter, with their CPU, cores and RAM.

```sql
SELECT
name,
core,
cpu,
ram
FROM ovh.dedicated_cloud.datacenter_orderable_host_profiles
WHERE datacenter_id = '{{ datacenter_id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
