<TabItem value="get">

Get a hosting location

```sql
SELECT
id,
city,
country_code,
pcc_zone,
region,
region_location
FROM ovh.dedicated_cloud.locations
WHERE pcc_zone = '{{ pcc_zone }}' -- required
;
```
</TabItem>
<TabItem value="get_by_service_name">

Get a hosting location

```sql
SELECT
id,
city,
country_code,
pcc_zone,
region,
region_location
FROM ovh.dedicated_cloud.locations
WHERE service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List hosting locations

```sql
SELECT
id,
city,
country_code,
pcc_zone,
region,
region_location
FROM ovh.dedicated_cloud.locations
WHERE x_pagination_mode = '{{ x_pagination_mode }}'
;
```
