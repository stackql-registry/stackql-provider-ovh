Returns the CA certificate, in PEM format, used to verify the connection to the service. (Beta version)

```sql
SELECT
ca
FROM ovh.public_cloud_analytics.clickhouse_certificates
WHERE service_id = '{{ service_id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
