## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the database name and whether it is the engine default database. (Beta version)

```sql
SELECT
id,
name,
checksum,
created_at,
default,
updated_at
FROM ovh.public_cloud_analytics.clickhouse_databases
WHERE database_id = '{{ database_id }}' -- required
AND service_id = '{{ service_id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">
