Returns, as an asynchronous task, the evidences of spam stored for an IP of the access.

```sql
SELECT
error,
result,
status
FROM ovh.xdsl.anti_spams_evidences
WHERE ip = '{{ ip }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
