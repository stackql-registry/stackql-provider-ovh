## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the anti-spam status of an IP of the access, with its detection date and last spam detection date.

```sql
SELECT
date,
ip,
last_spam_detected,
status
FROM ovh.xdsl.anti_spams
WHERE ip = '{{ ip }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the IPs of the access detected as sending spam.

```sql
SELECT
date,
ip,
last_spam_detected,
status
FROM ovh.xdsl.anti_spams
WHERE service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
