## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the status, creation date and expiration date of the copy.

```sql
SELECT
id,
creation_date,
expiration_date,
last_update,
status
FROM ovh.hosting_private_database.database_copies
WHERE database_name = '{{ database_name }}' -- required
AND id = '{{ id }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the IDs of the copies of the database.

```sql
SELECT
id,
creation_date,
expiration_date,
last_update,
status
FROM ovh.hosting_private_database.database_copies
WHERE database_name = '{{ database_name }}' -- required
AND service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

```sql
last_update,
status
;
```

## `DELETE` examples

<Tabs
    defaultValue="delete"

Deletes the copy immediately, before its expiration date. A deleted copy can no longer be restored.

```sql

WHERE database_name = '{{ database_name }}' --required
AND id = '{{ id }}' --required
AND service_name = '{{ service_name }}' --required
;
```
