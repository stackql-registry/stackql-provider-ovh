## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Returns the configuration parameters with their current, default and available values, and whether the last update is applied.

```sql
SELECT
task_id,
details,
last_update,
status
FROM ovh.hosting_private_database.configs
WHERE service_name = '{{ service_name }}' -- required
;
```
</TabItem>
</Tabs>


## Lifecycle Methods

EXEC variables use wire (API) names.

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Updates the given configuration parameters as key-value pairs. Returns the configuration, whose status stays at updating until the change is applied.

```sql
EXEC ovh.hosting_private_database.configs.update 
@serviceName='{{ serviceName }}' --required 
@@json=
'{
"parameters": "{{ parameters }}"
}'
;
```
</TabItem>
</Tabs>
