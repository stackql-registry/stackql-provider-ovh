List server interface details. Returns the attached interfaces with the server each one belongs to.

```sql
SELECT
name,
dedicated_server,
dedicated_server_interface
FROM ovh.vrack.dedicated_server_interface_details
WHERE service_name = '{{ service_name }}' -- required
;
```
