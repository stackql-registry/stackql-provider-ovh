## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a vRack. Returns the name and description of the vRack.

```sql
SELECT
name,
service_name,
description,
iam
FROM ovh.vrack.vracks
WHERE service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List vRacks. Returns the service names of the vRacks of the account.

```sql
SELECT
name,
service_name,
description,
iam
FROM ovh.vrack.vracks
WHERE iam_tags = '{{ iam_tags }}'
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

## Lifecycle Methods

EXEC variables use wire (API) names.

<Tabs
    defaultValue="confirm_termination"
    values={[
        { label: 'confirm_termination', value: 'confirm_termination' },
        { label: 'terminate', value: 'terminate' }
    ]}
>
<TabItem value="confirm_termination">

Confirm service termination. Terminates the service with the token sent by email to the admin contact. A reason, a future use and a comment can be given.

```sql
EXEC ovh.vrack.vracks.confirm_termination 
@serviceName='{{ serviceName }}' --required 
@@json=
'{
"commentary": "{{ commentary }}", 
"futureUse": "{{ futureUse }}", 
"reason": "{{ reason }}", 
"token": "{{ token }}"
}'
;
```
</TabItem>
<TabItem value="terminate">

Request service termination. Starts the termination of the service. The admin contact receives a token by email, to confirm with the `confirmTermination` call.

```sql
EXEC ovh.vrack.vracks.terminate 
@serviceName='{{ serviceName }}' --required
;
```
</TabItem>
</Tabs>
