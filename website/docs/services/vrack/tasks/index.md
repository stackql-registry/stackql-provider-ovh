## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a task. Returns the function, status, target and dates of the task.

```sql
SELECT
id,
order_id,
service_name,
function,
last_update,
status,
target_domain,
todo_date
FROM ovh.vrack.tasks
WHERE service_name = '{{ service_name }}' -- required
AND task_id = '{{ task_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

List tasks. Returns the identifiers of the tasks run on the vRack.

```sql
SELECT
id,
order_id,
service_name,
function,
last_update,
status,
target_domain,
todo_date
FROM ovh.vrack.tasks
WHERE service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>
