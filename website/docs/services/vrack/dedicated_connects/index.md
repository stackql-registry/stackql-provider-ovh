## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a link. Returns the name of the Dedicated Connect link.

```sql
SELECT
name
FROM ovh.vrack.dedicated_connects
WHERE name = '{{ name }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List links. Returns the names of the Dedicated Connect links attached to the vRack.

```sql
SELECT
name
FROM ovh.vrack.dedicated_connects
WHERE service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>
