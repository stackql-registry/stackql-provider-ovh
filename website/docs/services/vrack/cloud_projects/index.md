## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a project. Returns the attached Public Cloud project and its vRack.

```sql
SELECT
project,
vrack
FROM ovh.vrack.cloud_projects
WHERE project = '{{ project }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List projects. Returns the identifiers of the Public Cloud projects attached to the vRack.

```sql
SELECT
project,
vrack
FROM ovh.vrack.cloud_projects
WHERE service_name = '{{ service_name }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>
