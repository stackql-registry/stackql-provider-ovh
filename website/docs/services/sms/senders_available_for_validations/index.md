List senders available for validation. Returns the senders linked to the customer account or to OVHcloud services, which can be validated automatically.

```sql
SELECT
referer,
sender
FROM ovh.sms.senders_available_for_validations
WHERE service_name = '{{ service_name }}' -- required
AND referer = '{{ referer }}'
;
```
