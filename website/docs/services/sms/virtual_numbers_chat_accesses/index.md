## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Get the web access. Returns the web access to the chat application of the virtual number: its URL and creation date.

```sql
SELECT
id,
creation_date,
url
FROM ovh.sms.virtual_numbers_chat_accesses
WHERE number = '{{ number }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
</TabItem>
</Tabs>
