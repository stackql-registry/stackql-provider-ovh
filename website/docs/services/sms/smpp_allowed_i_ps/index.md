<Tabs
    defaultValue="update"

<TabItem value="update">

Adds or removes IP addresses allowed to connect to the SMPP account, depending on the action.

```sql
UPDATE ovh.sms.smpp_allowed_i_ps
SET 
action = '{{ action }}',
ips = '{{ ips }}'
WHERE 
service_name = '{{ service_name }}' --required
AND action = '{{ action }}' --required
AND ips = '{{ ips }}' --required;
```
