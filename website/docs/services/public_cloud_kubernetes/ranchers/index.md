## `SELECT` examples

    defaultValue="get"
    values={[

    ]}
>
<TabItem value="get">

Get a managed Rancher service

```sql
SELECT
id,
created_at,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at
FROM ovh.public_cloud_kubernetes.ranchers
WHERE rancher_id = '{{ rancher_id }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">

List managed Rancher services

<TabItem value="update">

Update an existing managed Rancher service

```sql
UPDATE ovh.public_cloud_kubernetes.ranchers
SET 
target_spec = '{{ target_spec }}'
WHERE 
rancher_id = '{{ rancher_id }}' --required
AND project_id = '{{ project_id }}' --required unless OVH_CLOUD_PROJECT_SERVICE is set
AND target_spec = '{{ target_spec }}' --required
RETURNING
id,
created_at,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at;
```
</TabItem>
