Get prices and contracts information

```sql
SELECT
order_id,
contracts,
details,
prices,
url
FROM ovh.order.telephony_security_deposits
WHERE amount = '{{ amount }}' -- required
AND billing_account = '{{ billing_account }}' -- required
;
```
