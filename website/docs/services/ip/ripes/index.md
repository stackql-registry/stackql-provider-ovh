## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Get RIPE information. Returns the netname and description registered for the block in the RIPE database, as shown in WHOIS.

```sql
SELECT
description,
netname
FROM ovh.ip.ripes
WHERE ip = '{{ ip }}' -- required
;
```
</TabItem>
</Tabs>

<Tabs

<TabItem value="update">

Update RIPE information. Changes the netname and description registered for the block in the RIPE database, as shown in WHOIS.

```sql
UPDATE ovh.ip.ripes
SET 
description = '{{ description }}',
netname = '{{ netname }}'
WHERE 
ip = '{{ ip }}' --required;
```
