## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get an IP service. Returns the service's IP block, type, routed service, organization, country, IAM metadata and whether it can be terminated. (Beta version)

```sql
SELECT
organisation_id,
can_be_terminated,
country,
description,
iam,
ip,
routed_to,
type
FROM ovh.ip.services
WHERE service_name = '{{ service_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List IP services. Returns the service names of your IP subscriptions, filterable by IAM tags. Each name is the serviceName of the other service calls. (Beta version)

```sql
SELECT
organisation_id,
can_be_terminated,
country,
description,
iam,
ip,
routed_to,
type
FROM ovh.ip.services
WHERE iam_tags = '{{ iam_tags }}'
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

## Lifecycle Methods

EXEC variables use wire (API) names.

<Tabs
    defaultValue="change_contact"
    values={[
        { label: 'change_contact', value: 'change_contact' },
        { label: 'confirm_termination', value: 'confirm_termination' },
        { label: 'terminate', value: 'terminate' }

<TabItem value="change_contact">

Change service contacts. Starts a procedure to change the admin, tech or billing contact of the service. (Beta version)

```sql
EXEC ovh.ip.services.change_contact 
@serviceName='{{ serviceName }}' --required 
@@json=
'{
"contactAdmin": "{{ contactAdmin }}", 
"contactBilling": "{{ contactBilling }}", 
"contactTech": "{{ contactTech }}"
}'
;
```
</TabItem>
<TabItem value="confirm_termination">

Confirm service termination. Terminates the service with the token sent by email to the admin contact. A reason, a future use and a comment can be given. (Beta version)

```sql
EXEC ovh.ip.services.confirm_termination 
@serviceName='{{ serviceName }}' --required 
@@json=
'{
"commentary": "{{ commentary }}", 
"futureUse": "{{ futureUse }}", 
"reason": "{{ reason }}", 
"token": "{{ token }}"
}'
;
```
</TabItem>
<TabItem value="terminate">

Request service termination. Starts the termination of the service. The admin contact receives a token by email, to confirm with the `confirmTermination` call. (Beta version)

```sql
EXEC ovh.ip.services.terminate 
@serviceName='{{ serviceName }}' --required
;
```
</TabItem>
</Tabs>
