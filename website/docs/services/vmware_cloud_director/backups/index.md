## `SELECT` examples

<Tabs

<TabItem value="get">

Returns the backup service: offers with their quota and used space, availability zone and status.

```sql
SELECT
id,
created_at,
current_state,
current_tasks,
iam,
resource_status,
target_spec,
updated_at
FROM ovh.vmware_cloud_director.backups
WHERE backup_id = '{{ backup_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

Returns the backup services, with their offers and status.

```sql
SELECT
id,
created_at,
current_state,
current_tasks,
iam,
resource_status,
target_spec,
updated_at
FROM ovh.vmware_cloud_director.backups
WHERE x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND iam_tags = '{{ iam_tags }}'
;
```

## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Replaces the backup offers of the service: BRONZE, SILVER or GOLD, each with a quota in TB. An offer left out of the list is removed. Accepted only when the service is `READY`, then applied asynchronously: `currentState` catches up with `targetSpec`.

```sql
UPDATE ovh.vmware_cloud_director.backups
SET 
target_spec = '{{ target_spec }}'
WHERE 
backup_id = '{{ backup_id }}' --required
AND target_spec = '{{ target_spec }}' --required
RETURNING
id,
created_at,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at;
```
</TabItem>
</Tabs>
