<TabItem value="get">

Returns the virtual datacenter: commercial range, region, vCPU, memory, storage and IP quotas, and vRack.

```sql
SELECT
id,
current_state,
current_tasks,
iam,
resource_status,
target_spec,
updated_at
FROM ovh.vmware_cloud_director.organization_virtual_data_centers
WHERE organization_id = '{{ organization_id }}' -- required
AND virtual_data_center_id = '{{ virtual_data_center_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Updates the description and the vCPU speed of the virtual datacenter. Accepted only when the virtual datacenter is `READY`, then applied asynchronously: `currentState` catches up with `targetSpec`.

```sql
UPDATE ovh.vmware_cloud_director.organization_virtual_data_centers
SET 
target_spec = '{{ target_spec }}'
WHERE 
organization_id = '{{ organization_id }}' --required
AND virtual_data_center_id = '{{ virtual_data_center_id }}' --required
AND target_spec = '{{ target_spec }}' --required
RETURNING
id,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at;
```
</TabItem>
