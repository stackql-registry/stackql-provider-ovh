## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },

    ]}
>
<TabItem value="get">

Retrieves specific vault details

```sql
SELECT
id,
created_at,
current_state,
current_tasks,
iam,
resource_status,
target_spec,
updated_at
FROM ovh.backup_services.tenant_vaults
WHERE backup_services_id = '{{ backup_services_id }}' -- required
AND vault_id = '{{ vault_id }}' -- required
;
```
</TabItem>
<TabItem value="list">

Lists vaults for your tenant

```sql
SELECT
id,
created_at,
current_state,
current_tasks,
iam,
resource_status,
target_spec,
updated_at
FROM ovh.backup_services.tenant_vaults
WHERE backup_services_id = '{{ backup_services_id }}' -- required
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
AND iam_tags = '{{ iam_tags }}'
;
```
</TabItem>
</Tabs>

<TabItem value="update">

Updates vault display name and cloud repository

```sql
UPDATE ovh.backup_services.tenant_vaults
SET 
name = '{{ name }}'
WHERE 
backup_services_id = '{{ backup_services_id }}' --required
AND vault_id = '{{ vault_id }}' --required
AND name = '{{ name }}' --required
RETURNING
id,
created_at,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at;
```
