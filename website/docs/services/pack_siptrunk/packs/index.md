## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get this object properties

```sql
SELECT
pack_name,
iam
FROM ovh.pack_siptrunk.packs
WHERE pack_name = '{{ pack_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List available services

```sql
SELECT
pack_name,
iam
FROM ovh.pack_siptrunk.packs
WHERE iam_tags = '{{ iam_tags }}'
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>

EXEC variables use wire (API) names.

    defaultValue="change_contact"
    values={[

<TabItem value="change_contact">

Change service contacts. Starts a procedure to change the admin, tech or billing contact of the service.

```sql
EXEC ovh.pack_siptrunk.packs.change_contact 
@packName='{{ packName }}' --required 
@@json=
'{
"contactAdmin": "{{ contactAdmin }}", 
"contactBilling": "{{ contactBilling }}", 
"contactTech": "{{ contactTech }}"
}'
;
```
