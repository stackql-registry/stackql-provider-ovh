Get all the template usages options applicable to this partition.

```sql
SELECT
name,
description
FROM ovh.dedicated_nasha.partition_template_usages
WHERE partition_name = '{{ partition_name }}' -- required
AND service_name = '{{ service_name }}' -- required
;
```
