## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the bucket configuration and its current state.

```sql
SELECT
id,
checksum,
created_at,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at
FROM ovh.public_cloud_storage.object_buckets
WHERE bucket_name = '{{ bucket_name }}' -- required
AND project_id = '{{ project_id }}' -- required unless OVH_CLOUD_PROJECT_SERVICE is set
;
```
</TabItem>
<TabItem value="list">


## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Updates the bucket configuration. Send the current checksum to prevent overwriting a concurrent change. Without it, the last write wins.

```sql
UPDATE ovh.public_cloud_storage.object_buckets
SET 
checksum = '{{ checksum }}',
target_spec = '{{ target_spec }}'
WHERE 
bucket_name = '{{ bucket_name }}' --required
AND project_id = '{{ project_id }}' --required unless OVH_CLOUD_PROJECT_SERVICE is set
AND target_spec = '{{ target_spec }}' --required
RETURNING
id,
checksum,
created_at,
current_state,
current_tasks,
resource_status,
target_spec,
updated_at;
```
</TabItem>
</Tabs>

## Lifecycle Methods

EXEC variables use wire (API) names.

<Tabs
    defaultValue="bulk_delete_objects"
    values={[
        { label: 'bulk_delete_objects', value: 'bulk_delete_objects' },
        { label: 'presign', value: 'presign' }

<TabItem value="bulk_delete_objects">

Deletes a list of objects in one request. To delete a large number of objects, use lifecycle rules instead. (Alpha version)

```sql
EXEC ovh.public_cloud_storage.object_buckets.bulk_delete_objects 
@bucketName='{{ bucketName }}' --required, 
@project_id='{{ project_id }}' --required unless OVH_CLOUD_PROJECT_SERVICE is set 
@@json=
'{
"objects": "{{ objects }}"
}'
;
```
</TabItem>
<TabItem value="presign">

Creates a temporary URL to download or upload an object without credentials. The URL expires after the given time. (Alpha version)

```sql
EXEC ovh.public_cloud_storage.object_buckets.presign 
@bucketName='{{ bucketName }}' --required, 
@project_id='{{ project_id }}' --required unless OVH_CLOUD_PROJECT_SERVICE is set 
@@json=
'{
"expiresIn": {{ expiresIn }}, 
"key": "{{ key }}", 
"method": "{{ method }}", 
"storageClass": "{{ storageClass }}", 
"versionId": "{{ versionId }}"
}'
;
```
</TabItem>
