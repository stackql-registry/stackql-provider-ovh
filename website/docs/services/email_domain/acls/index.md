## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get an ACL. Returns the OVHcloud account ID (`accountId`) that has been given access to the email service of the domain.

```sql
SELECT
account_id
FROM ovh.email_domain.acls
WHERE account_id = '{{ account_id }}' -- required
AND domain = '{{ domain }}' -- required
;
```
</TabItem>
<TabItem value="list">

List ACLs. Returns the OVHcloud account IDs (`accountId`) that have been given access to the email service of the domain.

```sql
SELECT
account_id
FROM ovh.email_domain.acls
WHERE domain = '{{ domain }}' -- required
AND x_pagination_mode = '{{ x_pagination_mode }}'
;
```
</TabItem>
</Tabs>
