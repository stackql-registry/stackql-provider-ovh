Get email account usage. Returns the number of emails, the maximum size in bytes of the mailbox (`quota`) and the date of the measure.

```sql
SELECT
date,
email_count,
quota
FROM ovh.email_domain.account_usages
WHERE account_name = '{{ account_name }}' -- required
AND domain = '{{ domain }}' -- required
;
```
