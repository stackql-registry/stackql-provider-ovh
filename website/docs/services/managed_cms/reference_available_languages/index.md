Returns the languages a website can be configured with at creation, with their display name. Filter them by CMS. (Alpha version)

```sql
SELECT
name,
code
FROM ovh.managed_cms.reference_available_languages
WHERE cms = '{{ cms }}' -- required
AND x_pagination_cursor = '{{ x_pagination_cursor }}'
AND x_pagination_size = '{{ x_pagination_size }}'
;
```
